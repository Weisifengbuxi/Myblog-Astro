## 2. 文章卡片 hover 擦亮动画（`source/css/home.css`，全文 15 行）

```css
#recent-posts > .recent-post-item:not(a)::before {
  content: "";
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 200%;
  background: linear-gradient(to right, transparent, white, transparent);
  transform: translateX(-200%);
  transition: transform 0.5s linear;
  z-index: 1;
}
#recent-posts > .recent-post-item:not(a):hover::before {
  transform: translateX(100%) skewX(-60deg);
}
```

要点：一条白色渐变从左侧扫到右侧，`translateX(-200%) → translateX(100%)`，
配合 `skewX(-60deg)` 形成斜向扫光，时长 `0.5s linear`。

## 4. 原版的问候语生成

```js
const generateWelcomeMessage = (pos, dist, ipDisplay, country, province, city) => `
    欢迎来自 <b>${pos}</b> 的朋友<br>
    您当前距博主约 <b>${dist}</b> 公里！<br>
    您的IP地址：<b class="ip-address">${ipDisplay}</b><br>
    ${getTimeGreeting()}<br>
    Tip：<b>${getGreeting(country, province, city)}</b>
`;
```

`getGreeting` 逐级回退：`国家 → 省 → 市`，每级取不到就用该级的「其他」。

## 5. 需要修正的现存问题

- **距离行重复**：现在同时显示「你当前距博主约 N 公里！」和另一条同名行，
  因为与 `./migration/NOTES-welcome-card.md` 里记录的坐标/精度问题叠加。
  应合并为**一条**，且数值来源要准确。
- **位置不准确**：原版用 IP 的城市级定位。用户反馈不准 —— 应对齐原版语义：
  「欢迎来自」用**城市级**位置（IP 或定位），但不要用浏览器定位的坐标去
  覆盖显示用的地名，避免出现「显示广州、距离按精确定位算」的割裂。
  距离应基于**同一来源**的坐标计算。
