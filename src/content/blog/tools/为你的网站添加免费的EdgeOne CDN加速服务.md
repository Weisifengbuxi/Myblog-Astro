很多朋友的网站没有购买服务器，因此部署在国外的服务器上，比如 Vercel。但由于 Vercel 国内被墙了，因此没法使用 CDN 加速。这使得网站访问速度十分缓慢。

听说腾讯云有相关免费 CDN 就去试了一下，没想到居然这么良心，免费套餐就能满足大部分个人站长的需求，而且配置起来也非常简单。分享一下如何为你的网站添加腾讯云 CDN 加速服务，保护你的网站同时让你的网站访问速度飞起来！

话不多说，直接上教程。

:::success no-icon
在开始前，你需要为你的网站备案，并注册一个腾讯云的账号（最好实名认证）
:::
## 将你的网站部署在 EdgeOne 上
点击访问该链接[EdgeOne page](https://console.cloud.tencent.com/edgeone/pages)，点击创建项目，选择导入 Git 仓库，这时候你需要将你的网站代码上传到 GitHub，再将 GitHub 仓库地址填写进去，验证。之后选择你的项目进入。

![edgeone1.png](https://images.weserv.nl/?url=https://cdn.jsdelivr.net/gh/Weisifengbuxi/tuchuang@main/img/edgeone1.png)

进入你的项目之后点击开始部署，注意项目中不要有单个大小超过**25MB**的文件，否则会部署失败。

## 配置 CDN 加速
现在你有了免费套餐资格，接下来就可以配置 CDN 加速了。

进入你的[EdgeOne 项目](https://console.cloud.tencent.com/edgeone/zones)，点击新增站点，点击开始接入即可，之后将你的兑换码兑换个人版免费版即可（只能兑换这个）。

接下来的配置请根据你的网站实际情况进行配置即可，主要配置以下几个选项：
1. **站点域名**：填写你的网站域名
2. **源站配置**：填写你的网站源站地址，如果是从腾讯云购买的域名可以一键配置，否则得用 cname 配置
3. **加速区域**：选择全球加速
4. **协议配置**：建议开启 HTTPS，选择自动申请免费证书
5. **缓存配置**：建议开启静态资源缓存
6. **防护配置**：这个在免费版中好像不能设置

如果你是新手第一次配置，可以去看张洪 heo 大佬的文章[腾讯云 EdgeOne 免费无限量 CDN 流量，良心到哭了（抽兑换码）](https://blog.zhheo.com/p/5e50rt80.html)

配置完之后效果非常显著。检测访问全国都是深绿色，没有闪电标志，最关键的是长期完全免费的。这次真的得感谢腾讯云，良心到家了！
